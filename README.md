# الذئبة الحمراء | Lupus

منصة عربية RTL مبنية حاليًا كموقع ثابت على GitHub Pages، ومصممة لتتوسع لاحقًا إلى نظام حسابات ومساهمين وPatient-Reported Outcomes.

## الحالة الحالية
- صفحة رئيسية مبنية حول رحلة المريض.
- أقسام مستقلة: افهم الذئبة، التعايش، العلاج، الحمل، الأسئلة الشائعة، وعن المنصة.
- صفحة `assessment.html` محجوزة مستقبلًا لـ Patient-Reported Outcome Assessment بدون جمع بيانات حاليًا.
- قسم مقالات الأطباء.
- دليل للأطباء المساهمين `doctors.html`.
- نموذج ملف طبيب `doctor-template.html`.
- نموذج مقال طبي محكوم بالمراجعة `article-template.html`.
- معاينة تصميمية للوحة الإدارة `admin-preview.html`.
- دليل مساهمة ومراجعة في `CONTRIBUTING.md`.

## النشر
GitHub Pages: الفرع `main` والمجلد `/root`.

## ملاحظة أمنية
`admin-preview.html` مجرد نموذج بصري. لوحة الإدارة الحقيقية وحسابات المرضى وبيانات PRO يجب أن تُبنى على Backend آمن مع Authentication وصلاحيات وقاعدة بيانات مناسبة، وليس على GitHub Pages وحده.

## دورة المحتوى المقترحة
Draft → Submitted → Medical Review → Changes Requested → Approved → Published

المالك يحتفظ بصلاحية النشر والتحكم النهائي، بينما الطبيب المساهم يكتب ويرسل للمراجعة فقط.
