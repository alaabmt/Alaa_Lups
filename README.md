# الذئبة الحمراء | Lupus — Website v1

نسخة أولى عربية بالكامل (RTL) ومصممة لتعمل مباشرة على GitHub Pages بدون أي build أو قاعدة بيانات.

## التشغيل
افتح `index.html` مباشرة في المتصفح.

## النشر على GitHub Pages
1. ارفع `index.html` و `styles.css` إلى الفرع `main`.
2. من Settings > Pages اختر Deploy from a branch ثم `main` و `/root`.

## المرحلة الحالية
- الصفحة الرئيسية وتجربة المريض الأساسية.
- أقسام افهم الذئبة، التعايش، العلاج، الحمل، مقالات الأطباء.
- مكان محجوز لـ Patient-Reported Outcome Assessment تحت «قيّم حالتك».
- لا توجد حسابات مرضى أو قاعدة بيانات أو استبيان فعلي حتى الآن.

## المرحلة التالية المقترحة
تحويل الأقسام إلى صفحات مستقلة ثم إضافة نظام مساهمة الأطباء والمراجعة قبل النشر.
